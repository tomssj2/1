# Bozinis Center

Website for **Bozinis Center**, a hardware store in Kopanos, Imathia, Greece. It sells plumbing, heating, solar water heater, bathroom and tool supplies.

- Instagram: https://www.instagram.com/boziniscenter/
- Facebook: https://www.facebook.com/BOZINIS.CENTER/

It's a plain static site with no build step. Open `index.html` in a browser, or upload this
folder to any static host. The page is in Greek by default, and the ΕΛ / EN button switches it to English.

```
index.html   page markup (Products, About, Stores, Contact)
styles.css   theme: charcoal + safety orange
script.js    mobile nav and ΕΛ / EN toggle (English strings live here)
```

## Before going live, check

- **Opening hours** (Stores section in `index.html`). The current ones are placeholders
  based on typical Greek shop hours. Confirm them with the store.
- **Product descriptions.** They're generic for each category. Add brands the store carries
  if they want them listed.
- **Photos / logo.** None are included. The brand mark is text only. Add real store photos
  or the logo from the Instagram page if available.

The store details came from public listings: Themistokleous 12 (2332 041 494), Ermou 87
(2332 042 609), and boziniscenter@gmail.com.
